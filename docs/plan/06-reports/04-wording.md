# レポートとホームの文言(確定用)

状態: **承認済み**(2026-11-24、案のまま)

方針(AGENTS.md): 責めない。評価ラベルを使わない。「遅れています」「増えました」を使わない。続いたこと・保てたことを成果として扱う。
デザイン(docs/design)にある文言はそのまま使い、足りない場面だけ案を足した。{ } は差し込む値。

## 見出しと期間

| 場面 | 文言 |
| --- | --- |
| 月半ばの見出し | {n}月前半のレポート |
| 月末の見出し | {n}月のレポート |
| 期間 | {n}月{開始日}日〜{最終日}日 |
| タブの移動 | 前のレポート / 次のレポート |
| 公開済みなし | 最初のレポートは {日付(曜日)} に届きます。 |

## 記録できた日

| 場面 | 文言 |
| --- | --- |
| 見出し | 記録できた日 |
| 数 | {n} 日 / {m}日 |
| 一言(すべての日) | この期間、毎日記録できました。 |
| 一言(半分以上) | この2週間、よく続けられました。(月末は「この1か月、よく続けられました。」) |
| 一言(半分未満) | 記録できた日の分だけ、体重の流れが見えてきます。途切れても、また今日から。 |

期間が2週間・1か月より短い最初のレポートでは「この期間、」にする。
