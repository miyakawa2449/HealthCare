# フェーズ6: レポート 計画

作成日: 2026-11-24
状態: **実装済み・実機確認待ち**(2026-11-24 に承認・実装。Codex レビュー3回でマージ可。main 未マージ)
ブランチ: `feature/phase6-reports`

フェーズ5までで、計画が自動で進み、カードとロードマップ画面で伝えられるようになった。
このフェーズでは、月半ば(1〜15日)と月末(1日〜月末)のレポートを作る。
体組成(体脂肪率・除脂肪量)を初めて画面に出すフェーズなので、コンセプト上の制約(月半ばは方向だけ、数値は月末だけ)をテストで固める。

## 対象

### A. 集計(WeightCore、TDD)

| # | 内容 | 実装する型 |
| --- | --- | --- |
| A1 | レポートの期間(月半ば 1〜15日 / 月末 1日〜月末)、公開日、計画の開始日より前を除く | `ReportPeriod` |
| A2 | 記録できた日(期間内で体重の記録がある日数、日ごとの有無) | `RecordContinuity` |
| A3 | 体重の流れ(期間の前の基準の7日平均 → 期間の最終日の7日平均)、最終日の目安と進み具合 | `WeightReport` |
| A4 | 体組成の代表値(期間の最終日に終わる7日間の平均)と変化の方向(下がった / 横ばい / 上がった) | `BodyComposition`、`CompositionDirection` |
| A5 | その時点のフェーズを日付から引く(過去のレポートの目安とステージ番号に使う) | `PhaseTimeline` |
| A6 | レポートの閾値を1か所にまとめる(plan.json に保存しない別の設定値) | `ReportSettings` |

### B. データ層(アプリ)

| # | 内容 |
| --- | --- |
| B1 | `PlanRecord.phaseHistory`(省略可能)。フェーズが変わる操作(自動遷移、見直しの採用、元の計画に戻す、85日目の進む、早期到達)で追記する |
| B2 | 既存の plan.json(履歴なし)は、今のフェーズだけの履歴として読む |
| B3 | `ReportBuilder`: 取得済みの体重・体脂肪率と計画からレポートの一覧を作る(純粋)。`DailySummary` にレポートの一覧と次のレポートを足す |
| B4 | レポートを開いたかどうかの保存(「届きました」の表示用) |

### C. 画面

| # | 内容 |
| --- | --- |
| C1 | レポートタブ: 最新のレポートを表示。過去のレポートへ移れる |
| C2 | 月半ばレポート: 記録できた日、体重の流れと目安・実際・進み具合、体組成の方向、今のステージ |
| C3 | 月末レポート: 上に加えて体組成の数値(前月と今月)、ステージと到達予定、実績ペースの一言(条件あり) |
| C4 | ホームの一番下に「次のレポート」カード(届いたら「届きました」) |
| C5 | 最新のレポートで計画見直しの条件が出ていれば、ホームと同じ提案カードを出す |

### 対象外(後のフェーズ)

- ウィジェットと受信(7)。「危険」判定時の医師相談の一言、測る時間帯の案内、期日指定モード、計画を作り直す画面(8)。
- レポートの PDF 書き出しや共有(外部送信をしない方針のため、作らない)。

## 実装の順番

1. A1・A2 `ReportPeriod`、`RecordContinuity`(WeightCore、TDD)
2. A4・A6 `BodyComposition`、`ReportSettings`(TDD)
3. A5 `PhaseTimeline` と A3 `WeightReport`(TDD)
4. B1・B2 `PlanRecord.phaseHistory`、既存 plan.json のフィクスチャテスト
5. B3・B4 `ReportBuilder`、`DailySummary` への追加、既読の保存
6. C1〜C3 レポート画面と `#Preview`
7. C4・C5 ホームの「次のレポート」カード、レポート内の提案カード
8. `swift test`、`xcodegen generate`、`xcodebuild test`、Codex レビュー、実機確認

コミットは 1+2、3、4、5、6、7 の6つ程度。

## 確認方法

```sh
cd WeightCore && swift test && cd ..
xcodegen generate
xcodebuild -project WeightApp.xcodeproj -scheme WeightApp \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' test
```

- 集計と期間の境界(2月、うるう年、月末が31日・30日、計画の開始日を含む月)はテストで固める。
- 「月半ばでは体組成の数値を出さない」は、表示用のモデル(`ReportContent`)の段階でテストする(画面に渡す値に数値が含まれないこと)。
- `#Preview` で月半ば・月末・最初のレポート・記録が少ない・維持期間・データなしを確認する。
- 実機では、2026-10-24 開始の計画で「10月のレポート(24〜31日)」と「11月前半のレポート」が出ること、体脂肪率が HealthPlanet から読めていることを確認する(11月30日に「11月のレポート」が出るかは当日に確認)。
