# カードとロードマップ画面の文言(確定用)

状態: **回答待ち**。直したい文言は「案」の欄を書き換えてください。そのままでよければ末尾の回答欄に「このままでよい」と書いてください。

方針(AGENTS.md): 責めない。評価ラベルを使わない。「遅れています」「増えました」を使わない。続いたこと・保てたことを成果として扱う。
