## 対象

### A. フェーズの自動遷移(WeightCore + データ層)

| # | 内容 | 実装する型 |
| --- | --- | --- |
| A1 | ステージ到達の検出: 減量中、起点以降で最初に7日平均(丸め)が境界以下になった日を到達日にし、維持期間へ(最終ステージなら維持モードへ) | `PhaseProgression`(WeightCore) |
| A2 | 卒業: 維持期間で `MaintenanceJudgment` が `graduated(on:)` を返したら、その日の7日平均と日付を起点に次のステージの減量中へ | `PhaseProgression` |
| A3 | 遷移のたびに到達予定日を計算し直す(`Roadmap.rescheduled(from:)`)。連鎖(卒業した日に次の境界も下回っている等)は安定するまで繰り返す(上限あり) | `PhaseProgression` |
| A4 | 遷移と最初の区切りの到達を「出来事」として記録し、カードで伝える | `PlanEvent`、`PlanRecord.events` |
| A5 | 取得 → 遷移の適用 → 保存 → 判定 の流れ。最初の区切りの検出も `HomeModel` からここへ移す | `DailySummaryBuilder` |

### B. カード(ホーム画面の7日平均カードとステージカードの間)

| # | カード | 種類 | 選択肢 |
| --- | --- | --- | --- |
| B1 | 最初の区切りに届いた | 出来事 | 閉じる |
| B2 | ステージの区切りに届いた(維持期間へ) | 出来事 | 閉じる |
| B3 | 維持期間を終えて次のステージへ | 出来事 | 閉じる |
| B4 | 最終目標に届いた(維持モードへ) | 出来事 | 閉じる |
| B5 | 維持期間が12週間を超えた(85日目) | 提案 | 次のステージへ進む / 維持を続ける |
| B6 | 維持期間中に次の区切りまで減った(早期到達) | 提案 | 次のステージの到達として扱う / 維持を続ける |
| B7 | 計画の見直し(2%以上のずれが14日) | 提案 | この計画で進める / 元の計画のままにする |
| B8 | 速すぎるペース(月3%超) | 一言 | なし(条件が続く間だけ出る) |
| B9 | 維持の範囲から外れて14日(上 / 下) | 一言 | なし |
| B10 | 「元の計画に戻す」(見直しを採用した後、ロードマップ画面に置く) | 操作 | 戻す |

「最初の1か月」はステージカードの一言で済ませ、別のカードは出さない(03-decisions.md #6)。

### C. ロードマップ画面(タブの2つ目)

全ステージ(開始 → 区切り、到達予定日または到達日、いまどこか)、ステージ1の中の最初の区切り、各ステージ後の維持期間、最終目標、標準ペースの安全性(言葉)、見直し採用後の「元の計画に戻す」。

### 対象外(後のフェーズ)

- レポート(フェーズ6)。レポートの中で計画見直しを伝える部分も6。
- ウィジェットと受信(7)。「危険」判定時の医師相談の一言、測る時間帯の案内、期日指定モード(8)。
- 計画を作り直す(初回設定のやり直し)画面。

## 実装の順番

1. A1〜A3 `PhaseProgression`(WeightCore、TDD)
2. A4 `PlanEvent` と `PlanRecord` の項目追加、B のユーザー選択を `PlanRecord` の純粋な操作として実装(`PlanRecord+Actions`、テスト)
3. A5 `DailySummaryBuilder` に遷移の適用と保存を入れ、`HomeModel` の最初の区切りの検出を移す
4. カードの選別と優先順位(`HomeCards`、純粋、テスト)
5. `HomeModel` の操作(進む / 続ける / 採用 / 断る / 閉じる / 戻す)
6. カードの View(`EventCard`、`ProposalCard`、`NoticeCard`)と `#Preview`
7. ロードマップ画面(`RoadmapView`、`#Preview`)
8. `swift test`、`xcodegen generate`、`xcodebuild test`、Codex レビュー、実機確認

コミットは 1、2、3、4+5、6、7 の6つ程度。

## 確認方法

```sh
cd WeightCore && swift test && cd ..
xcodegen generate
xcodebuild -project WeightApp.xcodeproj -scheme WeightApp \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' test
```

- 遷移とカードの状態はテストで固める(実機では到達まで数か月かかるため)。
- `#Preview` でカードごとの見た目と文言を確認する。
- 実機では、既存の計画(2026-10-24 開始)が壊れず、ロードマップ画面が出ることを確認する。
